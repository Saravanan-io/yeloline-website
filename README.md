# yeloline-website

Modern architectural & structural engineering website for **Yeloline Construction**.

## Tech Stack
- React 19 + Vite
- GSAP & ScrollTrigger (3D Scroll Construction Sequence)
- Three.js
- Framer Motion
- Lucide React

## Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
npm run preview
```
